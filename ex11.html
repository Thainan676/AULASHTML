html

é uma linguagem usada para estruturar pagina web.ela organiza textos,imagens e link por meio de tag.

css

é uma linguagem que de ine o viual das paginas de web.Contrala cores,fonte e tamnho. Deixando o site mais organizado.

JS

Jjavascript é uma linguagem que torna página web interativas, permitido ações como cliques,animações e conteúdo dinâmico.
